# Native references

`FaceN`, `EdgeN` and array order identify current topology, not lasting intent. Keep role, owner, revision, geometry and semantic purpose with references. Re-resolve after topology changes; reject missing or ambiguous candidates instead of substituting the nearest item.

Writable predecessor geometry belongs to the selected Target Body's current Tip. Historical object measurements are not current predecessor references. Source may inform a decision, but native Target links must resolve to Target-owned objects. Observation selectors are not automatically writable link payloads; use the live command's accepted form.

Prefer Origin geometry, datums, sketches and early outputs when they express the intended dependency. Explicit edge groups need evidence for every member and shared parameter intent; different parameters require separate features. Tangent propagation does not authorize all-edge selection.
