# Feature guide

Infer an editable history from related faces, adjacency, material side and dependencies. Prefer a simple construction with measured dimensions; later cuts and dress-ups may hide its generating boundaries. Keep uncertainty explicit when several histories fit.

## Apply a card

Use [native references](../foundations/persistent-references.md) for writable selections. Bind template variables to actual session evidence, revisions, names and measurements; choose unused names for new objects. Templates illustrate calls, while live schemas define supported variants.

If a direct feature is unavailable, consider another evidenced editable construction within the current capabilities.
