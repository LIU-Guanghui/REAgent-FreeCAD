# Image to CAD

Inspect the selected reference images for silhouettes, proportions and visible features. Transfer a known dimension only to geometry with the same established scale and projection. When the scale of a key plane is unknown, ask for a dimension visible on that plane or use a user-authorized estimate and mark it unconfirmed. Explain relevant perspective and concealed geometry.

Build one editable solid. For each key visible feature, cite the relevant input image and the current Target observation. Cite a current Target view that shows the features being compared. Match the input viewpoint when possible and account for perspective when interpreting differences. Check explicitly supplied dimensions against native readback, and record approximate agreement and unresolved shape or scale.
