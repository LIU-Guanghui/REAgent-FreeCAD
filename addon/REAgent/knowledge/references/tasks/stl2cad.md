# STL to CAD

Interpret STL coordinates as millimetres. Use the Source bounds and both initial view boards to identify the primary shape, silhouettes and openings. When a local size or location matters, measure the spans of native mesh section contours. Use calibrated orthographic views for features that a section cannot resolve.

Build native editable features. Before delivery, read back the current Target bounds and feature dimensions and inspect a complete paired board. Cite the bounds and paired board in the checks. Explain the differences and the uncertainty introduced by the mesh.
