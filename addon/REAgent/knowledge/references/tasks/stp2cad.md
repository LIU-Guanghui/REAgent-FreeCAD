# STP to CAD

Reconstruct the one valid STP solid as a single editable Target part. Use Source global facts and both initial view boards for the overall form. Query source geometry locally for features whose dimensions or topology affect construction. Choose the simplest native parameters and feature history that preserve the intended shape.

Follow the [STP workflow](../workflow/entry.md) and [observation guidance](../workflow/observation.md). Before delivery, use a current geometric comparison and the complete paired board with matching Source and Target revisions. Use [parameter audit](../workflow/validation.md) when the task needs evidence about downstream editability. Report actual differences, limitations, and save state.
