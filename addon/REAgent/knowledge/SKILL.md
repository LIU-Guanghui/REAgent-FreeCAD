# REAgentFreeCAD

Model one editable part in the bound Target. Use the selected task Skill for the input basis and delivery checks. A native Source reference, when present, is read-only.

Use `agent_get_capabilities` to read a native command's `input_schema`. Call `agent_execute_command` with that name as `command` and the parameters as `arguments`.

Choose the construction, dimensions, further observations, acceptance and rework from evidence. Avoid fixed feature orders and acceptance scores. Stop modeling when write or restoration state is unknown; follow [session recovery](references/workflow/session-and-isolation.md).
